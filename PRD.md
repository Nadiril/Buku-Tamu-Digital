# Buku Tamu Digital - Frontend

## Deskripsi

Proyek ini adalah aplikasi frontend untuk sistem buku tamu digital. Aplikasi ini menyediakan antarmuka bagi tamu untuk mengisi data kunjungan secara online dan bagi admin untuk melihat daftar tamu.

## Fitur

- Formulir input tamu
- Validasi data input
- Tampilan daftar tamu
- Responsif untuk perangkat mobile dan desktop

## Instalasi

1. Pastikan Node.js dan npm sudah terpasang.
2. Masuk ke direktori frontend:

   ```bash
   cd /home/nadiril/Dokumen/buku-tamu-digital/frontend
   ```

3. Install dependensi:

   ```bash
   npm install
   ```

## Menjalankan Aplikasi

Jalankan perintah berikut untuk memulai aplikasi dalam mode pengembangan:

```bash
npm run dev
```

Buka browser dan akses aplikasi di alamat yang ditampilkan oleh server.

## Struktur Folder

- `src/` - Kode sumber frontend
- `public/` - Aset statis
- `package.json` - Daftar dependensi dan skrip

## Teknologi

- JavaScript / TypeScript
- Framework frontend (Vue/React/Svelte, disesuaikan dengan implementasi)
- CSS / Tailwind / Bootstrap (jika digunakan)
